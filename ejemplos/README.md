# Datos de ejemplo

Aquí vive la **copia maestra** de los datasets sintéticos del kit.

Cada skill que necesita datos lleva **su propia copia dentro** (`skills/<skill>/ejemplos/`).
No es un descuido: es lo que permite subir una skill suelta a Claude.ai y que funcione sin
arrastrar el repo entero. Si editas un dataset, edítalo aquí y propaga la copia.

| Fichero | Lo usan |
|---|---|
| `resenas-competencia.md` | `/el-hueco`, `/cliente-vivo` |

Todo lo que hay aquí es **inventado**. Sirve para practicar, no para sacar conclusiones
sobre ningún mercado real.
